Welcome to the AWS Matrix.

Choose a level. Each challenge gives you a simple analogy, the AWS explanation, and one exam-style question.

Study note: This is an unofficial learning aid. It is not affiliated with, endorsed by, or sponsored by AWS, Udemy, Stéphane Maarek, or Warner Bros. The Matrix references are used only as a learning metaphor. Always verify current exam scope against the official AWS exam guide.

How this game works

  • 1. Learn: read the short AWS explanation.
  • 2. See: use the Matrix analogy to create a mental picture.
  • 3. Decide: answer the question without looking it up.
  • 4. Unlock: correct answers earn XP and move you forward.
  • 5. Repeat: your progress is saved in this browser using localStorage.

Important distinction

The Matrix analogy is a memory aid, not an exact technical equivalence. AWS services have real technical behavior that you should learn separately.
