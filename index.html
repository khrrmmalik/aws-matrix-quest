Welcome to the AWS Matrix.

This version is deliberately harder. Read the scenario carefully. Several answers may look technically reasonable, but only one best matches the requirement.

Study note: This is an unofficial learning aid and is not affiliated with, endorsed by, or sponsored by AWS, Udemy, Stéphane Maarek, or Warner Bros. The Matrix references are used only as a learning metaphor. Always verify current exam scope and AWS service details against official AWS documentation.

How this game works

  • 1. Read the scenario. Don't immediately look for a familiar service name.
  • 2. Identify the requirement. Ask: compute, storage, networking, identity, monitoring, security, database, integration or cost?
  • 3. Choose the best answer. Some distractors are real AWS services.
  • 4. Learn from the explanation. The explanation appears after your answer.
  • 5. Build a streak. Three or more consecutive correct answers earn bonus XP.

Difficulty rule

This game intentionally uses scenario-based questions. The goal is to train the same mental skill needed when an exam question describes a business or technical requirement instead of simply naming the AWS service.
